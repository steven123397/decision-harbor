# 05 — 结果读取语义、保留期与幂等清理

**What to build:** 用户读取结果时得到明确可判别的语义，而不是一个笼统的错误：结果尚未产生、终态但没有可读快照、以及结果已过期各自返回不同状态。结果在保留期内可无限次重复读取，过期后明确不再可用；清理可以重复执行，只删除结果内容，不破坏长期审计事实。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 读取未产生结果的查询运行返回 HTTP 409 `result_not_ready`
- [ ] 读取处于终态但没有可读快照的查询运行返回 HTTP 409 `result_unavailable`
- [ ] 读取超过保留期的结果返回 HTTP 410 `result_expired`
- [ ] 保留期为 24 小时，以数据库记录的 `finished_at + 24h` 为准
- [ ] 保留期内重复读取返回同一结果快照
- [ ] 结果读取永远不重新执行 SQL
- [ ] 结果清理可以重复执行，重叠调度或进程重启都不破坏状态
- [ ] 清理只删除结果内容，不删除查询运行的长期审计事实
- [ ] 读取不存在的查询运行返回 HTTP 404 `query_run_not_found`
- [ ] 错误响应沿用统一 envelope，不泄漏数据库原始消息、堆栈、DSN 或凭据
