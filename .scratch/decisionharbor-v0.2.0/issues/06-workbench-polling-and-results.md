# 06 — 查询工作台接通轮询与结果

**What to build:** 业务用户在浏览器中提交 SQL 后不必保持一个长时间请求。工作台自行轮询，在排队、运行与成功之间自然推进，成功时展示列、行和截断提示；刷新页面后按运行标识恢复同一查询运行的状态与结果，浏览器会话不再是查询生命周期的所有者；策略拒绝与执行失败在界面上被清晰区分，让用户知道下一步该改 SQL 还是重试。

**Blocked by:** 03, 05

**Status:** ready-for-agent

- [ ] 提交后界面依次反映排队与运行状态，不再显示为一个不确定的长时间等待
- [ ] 成功运行展示结果列、行与截断提示，并显示行数与耗时等审计事实
- [ ] 刷新页面后按运行标识恢复同一查询运行的状态与结果
- [ ] 策略拒绝与执行失败使用不同的标题、图标与错误码说明，用户能判断下一步
- [ ] 结果尚未就绪时给出明确的等待反馈，不误导为失败
- [ ] 结果已过期或不可用时给出可区分的反馈与下一步提示
- [ ] 轮询在终态、页面卸载和不可恢复错误后停止
- [ ] 同一查询运行不产生重叠的轮询请求
- [ ] 使用轮询实现，不引入 SSE 或 WebSocket
