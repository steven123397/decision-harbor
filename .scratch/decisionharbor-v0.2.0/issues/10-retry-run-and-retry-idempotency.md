# 10 — 重试运行与重试幂等

**What to build:** 用户可以为失败或已取消的查询运行创建一个新的重试运行。它保留与来源运行的关联，但拥有独立的生命周期、审计事实和结果，原始运行的历史事实不被改写。重复的重试请求复用同一新运行；策略拒绝必须修改 SQL 后重新提交，成功运行不可重试，避免无意重复昂贵查询。

**Blocked by:** 02, 09

**Status:** ready-for-agent

- [ ] 为 `failed` 或 `cancelled` 运行创建重试时生成新的查询运行并返回 HTTP 202，新运行记录 `retry_of` 关联
- [ ] 重试运行拥有独立的标识、状态、时间事实和结果快照，不复用来源运行的可变事实
- [ ] 携带幂等键的重复重试返回同一新运行和 HTTP 202
- [ ] 重试键按来源运行 ID 隔离
- [ ] `rejected`、`succeeded`、`queued`、`running` 和 `cancelling` 运行返回 HTTP 409 `query_run_not_retryable`
- [ ] 策略拒绝的运行不能通过重试绕过策略判定，必须修改 SQL 后重新提交
- [ ] 重试运行同样经过完整的策略判定，不复用来源运行的历史判定结论
- [ ] 已记录取消意图的运行不会被自动执行尝试复活
- [ ] 成功运行不可重试
