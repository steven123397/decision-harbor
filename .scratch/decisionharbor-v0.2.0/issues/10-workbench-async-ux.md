# 10 — 工作台异步体验完整化

**What to build:** 查询工作台完整呈现异步生命周期：用户看到排队、运行、取消中与终态，页面刷新后按运行标识恢复状态；可对运行取消，并对允许状态执行重试；历史列表按分页合同展示近期运行；策略拒绝、执行失败、取消三种结果清晰区分，用户能采取正确下一步；结果暂不可用与过期有明确反馈。轮询（不引入 SSE 或 WebSocket）在终态、页面卸载和不可恢复错误后停止，同一运行不产生重叠请求；窄视口与键盘操作下保持基本可访问性。工作台不扩展为完整运营前端，也不做独立视觉改版。

**Blocked by:** 03 — 结果保留期、过期语义与幂等清理；06 — 取消请求链路与发布竞态；08 — 重试运行；09 — 运行历史分页

**Status:** ready-for-agent

- [ ] 工作台展示 `queued`、`running`、`cancelling` 与终态，并在页面刷新后按运行标识恢复状态
- [ ] 用户可对运行发起取消，且仅对允许状态提供重试；操作行为与 API 合同一致
- [ ] 历史列表按分页合同展示近期运行，可进入对应运行读取状态与结果
- [ ] 策略拒绝（修改 SQL 重新提交）、执行失败（可重试）、已取消（可重试）被清晰区分
- [ ] 结果未就绪（应继续轮询）、不可用与已过期三种反馈明确区分
- [ ] 轮询在终态、页面卸载和不可恢复错误后停止；同一运行不产生重叠请求；不使用 SSE/WebSocket
- [ ] 窄视口与键盘操作下可完成提交、轮询、取消、重试和读取结果，无内容重叠
- [ ] 浏览器测试覆盖提交、排队、运行、成功结果、策略拒绝、执行失败、取消、重试、历史和过期/不可用反馈，并检查桌面与窄视口无内容重叠
