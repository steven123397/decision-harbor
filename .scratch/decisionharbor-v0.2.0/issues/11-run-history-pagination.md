# 11 — 运行历史分页

**What to build:** 用户可以按创建时间倒序分页浏览查询运行历史，恢复近期分析工作。翻页是稳定的：即使新运行不断插入，已经取得游标的后续页面也不会重复或跳过首次快照中的记录。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 历史按 `(created_at DESC, id DESC)` 稳定排序
- [ ] 返回服务端生成的不透明游标
- [ ] `limit` 默认 20，合法范围为 1 到 100
- [ ] 无效 `limit` 或无效 `cursor` 返回 HTTP 422 `invalid_pagination`
- [ ] 下一页严格位于游标记录之后
- [ ] 相同创建时间以 ID 降序打破平局
- [ ] 新插入的查询运行不会使已取得游标的后续页面重复或跳过原快照中的记录
- [ ] 历史条目包含足以恢复近期工作的状态与摘要事实
- [ ] 分页响应沿用统一 `{data, error}` envelope
