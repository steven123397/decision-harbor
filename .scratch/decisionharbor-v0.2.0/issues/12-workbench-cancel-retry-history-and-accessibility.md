# 12 — 工作台的取消、重试、历史与可访问性

**What to build:** 业务用户能在工作台内完成完整生命周期操作：取消排队或运行中的查询、为失败或已取消的运行发起重试、浏览并恢复历史运行。这些能力在窄视口和纯键盘操作下同样可用，工作台可以改善信息层级、响应式与可访问性，但不扩展为完整运营前端。

**Blocked by:** 06, 09, 10, 11

**Status:** ready-for-agent

- [ ] 排队与运行中的查询运行提供取消入口，取消后状态收敛为 `cancelled` 并停止轮询
- [ ] 失败与已取消运行提供重试入口，重试后工作台跟随新的重试运行
- [ ] 不可重试的运行不提供重试入口，并说明原因
- [ ] 历史列表可分页浏览，并可选择某一运行恢复查看
- [ ] 结果过期或不可用时给出明确下一步提示，不误导为查询失败
- [ ] 桌面视口与窄视口下均无内容重叠
- [ ] 提交、轮询、取消、重试和结果读取均可通过键盘完成
- [ ] 关键状态变更可被辅助技术感知
- [ ] 界面清晰区分策略拒绝、执行失败与取消三种结局
