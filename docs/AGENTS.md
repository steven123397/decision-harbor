# docs 子树规则

本文件是 `docs/` 子树的局部规则，在 `docs/` 作用域内补充根 [`AGENTS.md`](../AGENTS.md)。冲突时以更近规则为准，但不得违背根规则中标注长期不变的边界。

## 目录职责（细则）

- `background/` — 已确认的外部输入：产品需求、技术约束。是产品背景的事实来源；不得改写以迁就实现。新增背景需用户确认。
- `design/` — 长期设计：范围、目标/非目标、术语与场景、不变量、模块边界、关键决策、失败/迁移、测试接缝与延后决策。`CONTEXT.md` 维护领域术语与概念边界。
- `plan/` — 阶段计划：阶段大计划、垂直任务、依赖、未规划区、机械/行为/共识验证。计划归档（如采用）放在 `history_plan.md`。
- `status/` — 当前事实：结论、进展、风险、下一步。只写当前确认的事实，不写推测；过时内容应更新而非累积。
- `index.md` — 导航与阅读入口，不复制正文。

## 写作约束

- 不在 `AGENTS.md` 或 `index.md` 中写入会频繁变化的版本事实、临时计划或待办清单。
- 设计与计划模板保持最小；没有真实内容时不批量生成专题文档。
- 跨 API、数据库、查询策略或运行环境的变更，需同步更新受影响的设计与测试文档。

## 默认遍历

- 默认按 `index.md` 的阅读顺序遍历正式文档。
- 当前不存在 `docs/temp/`；如未来需要非正式缓冲区，须先在根 `AGENTS.md` 与本文件中写入保护规则再创建。
