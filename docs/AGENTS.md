# docs/ 目录规则

本文件约束 `docs/` 目录；在其范围内覆盖根 `AGENTS.md`，未覆盖部分遵循根规则。

## 目录职责

- `background/`：已确认的外部输入、需求背景与技术约束来源，只读；不得为实现迁就而改写，新增背景需先经确认。
- `design/`：长期边界、领域模型、接口、数据与关键决策。
- `plan/`：阶段目标、任务切片、依赖、验证与交付边界。
- `status/`：当前事实、进展、风险与下一步，是唯一记录「现在怎样」的位置。
- `index.md`：只负责导航，不复制正文。

## 写入规则

- 同一事实只保留在一处：`background` 存来源，`design` 存决策，`plan` 存安排，`status` 存当前状态；不跨目录双写。
- 根 `README.md` 是人阅读入口，不改写背景约束。
- 当前阶段、临时计划与待办属于 `status/` 或 `plan/`，不写入根 `AGENTS.md`。
- 变更跨越 API、数据库、查询策略或运行环境时，同步更新受影响文档。
