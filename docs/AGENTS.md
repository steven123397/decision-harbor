# docs/ 子树规则

本文件是 `docs/` 目录的局部 Agent 规则，优先级高于根 `AGENTS.md` 中的通用描述，但不得覆盖根规则中的项目边界和安全约束。

## 目录职责

- `background/`：外部输入。产品需求、技术约束、数据契约说明。只读引用，实现不得改写。
- `design/`：长期设计。领域模型、接口契约、数据结构、关键决策及其理由。设计收敛后写入。
- `plan/`：执行计划。阶段目标、任务切片、依赖、验证标准。计划制定时写入。
- `status/`：当前状态。进展、风险、阻塞和下一步。阶段完成或状态变化时更新。
- `index.md`：导航入口。只维护链接和阅读顺序，不复制正文。

## 写作规则

- 每篇正式文档必须能从 `index.md` 到达。
- 新增正式文档后同步更新 `index.md`。
- 不在 `background/` 中写入实现细节；实现内生文档放入 `design/` 或 `plan/`。
- `status/` 只维护当前结论，不堆积历史日志；历史归档到 `plan/` 或删除。
- 模板见各目录 `README.md`；没有真实内容时不要批量生成专题文档。

## 禁止事项

- 不得在文档中记录密钥、连接字符串或真实用户数据。
- 不得把当前阶段临时事实写入根 `AGENTS.md`。
- 不得绕过 `index.md` 建立平行导航。
