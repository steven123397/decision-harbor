# 服务端游标取数与有界并发；容量耗尽是执行失败

执行器使用 PostgreSQL 服务端（命名）游标，结果集保留在数据库侧按块传输，`execute()` 不在 API 进程内存物化完整结果；达到行数上限即停止取数（截断语义见 ADR-0011）。只读执行使用独立有界连接池（默认 5）并与平台写入池隔离，服务层以同容量信号量闸门并发，不会产生超额连接。

容量满时新提交以 `QY_CAPACITY_EXCEEDED` 落为 `failed`——资源繁忙是执行失败，不是策略拒绝，避免用户查询耗尽审计写入能力；连接建立失败映射 `QY_ANALYTICS_UNAVAILABLE`，同样不留 `running` 审计记录。

## 被否方案

- 应用层物化完整结果集再截断：大结果集会撑爆 API 内存。

## 后果

- 容量限制只在单个 API 进程内生效；多实例部署需重新设计协调（见 issue tracker）。
