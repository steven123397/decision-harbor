# 业务结果返回 HTTP 200，4xx/5xx 只留给协议层【已被 ADR-0018 重开】

策略拒绝与执行失败返回 200 + `outcome`（`rejected` / `failed`）；400 只用于请求体不合法，404 只用于记录不存在（含非整数路径 id），503 只用于 `/ready` 未就绪。拒绝与失败是产品定义内的结果，都有审计记录和记录 id——用 envelope 区分让客户端统一按 `outcome` 分支，避免业务结果与传输错误混叠，失败响应也能携带记录标识。

此约定影响外部行为，实现与测试必须一致遵守。

> **状态：已被取代。** v0.2.0 异步生命周期引入真正的状态竞争（幂等冲突、结果就绪、后续取消与重试资格），「读到的事实」与「竞争失败」需要不同的状态码；替代决策与完整状态码合同见 ADR-0018。保留本文以记录演进脉络。
