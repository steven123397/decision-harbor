# 工作台不复制策略规则，无事前校验

提交前前端不做事事前校验：策略判定完全是 API 的职责，避免双写漂移。空输入禁用提交按钮是纯 UI 行为，不算策略判定。数值与时间戳按字符串渲染（见 ADR-0010），网络错误或非 200 响应展示通用失败信息与 HTTP 状态。

## v0.2.0 修正（#15）

异步生命周期的 HTTP 合同（ADR-0018）下，「非 200 响应一律通用失败信息」不再成立：提交受理是 202，策略拒绝是 422 且响应携带 rejected 运行记录——工作台按状态码分支，受理进入轮询推进（已受理/排队/执行中/取消中中间态逐态可辨），拒绝同步呈现拒绝码与可读说明；GET 读一律 200，按运行 state 分支。只有意外状态码（409 / 404 / 5xx 等）与网络错误继续展示通用失败信息与 HTTP 状态。「无事前校验、策略判定完全是 API 的职责」主结论不变。
