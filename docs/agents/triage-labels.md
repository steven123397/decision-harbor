# 分流标签

技能以五个规范分流角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个角色（如「打上 AFK-ready 分流标签」）时，使用表中对应的标签字符串。

若今后实际用语变化，修改右列即可，`/triage` 会照表应用而不会新建重复标签。
