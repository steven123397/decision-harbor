# 项目规范术语

本文档只维护项目特有的规范语言和概念边界。实现取舍见 [受治理查询链路](governed-query-path.md)。表字段与业务口径仍以 [数据契约](../../datasets/sales-analytics-v1/contract.json) 为准。

## 查询链路

### 查询运行

一次用户提交所产生的持久审计实体。它保存原始 SQL、策略判定、执行状态和审计事实，对应 HTTP 资源 `/api/v1/query-runs`。

- 推荐用词：查询运行
- 避免用词：查询任务、查询会话、job
- 相关概念：审计事实、策略判定

### 审计事实

查询运行上必须保留、且可通过 `GET /api/v1/query-runs/{id}` 再读出的字段：原始 SQL、策略判定或拒绝原因、执行状态、返回行数、耗时、错误摘要和创建时间。

- 推荐用词：审计事实
- 避免用词：日志、埋点
- 相关概念：查询运行

### 策略判定

查询策略模块对一条输入给出的结论：允许执行，或因语句形态、对象范围或未允许函数拒绝。超长输入在进入解析前由查询运行服务拒绝，同样记为 `rejected`。判定发生在任何用户 SQL 到达 `analytics` 之前。

- 推荐用词：策略判定
- 避免用词：校验、过滤、脱敏
- 相关概念：对象访问范围、查询运行

### 对象访问范围

策略允许引用的分析对象集合。首轮仅包含 `analytics` 库中契约规定的五张业务表，不含系统目录、平台对象或其他未授权关系。

- 推荐用词：对象访问范围
- 避免用词：权限名单、白名单表（单独使用时无法表达 schema 与作用域）
- 相关概念：策略判定、分析只读身份

## 身份与数据

### 平台身份

API 用来读写 `platform` 的应用身份。它创建和读取查询运行，不执行用户 SQL，也不查询分析表。

- 推荐用词：平台身份
- 避免用词：管理员、超级用户
- 相关概念：分析只读身份、分析所有者身份、查询运行

### 分析只读身份

查询执行器用来在 `analytics` 上运行已放行 SQL 的独立数据库身份。它只有业务表的 `SELECT`，不能写入任一逻辑库，也不能访问 `platform`。

- 推荐用词：分析只读身份
- 避免用词：查询用户、只读账号（单独使用时无法区分库）
- 相关概念：平台身份、分析所有者身份、对象访问范围

### 分析所有者身份

仅用于 `analytics` 的迁移与幂等 seed 的独立数据库身份。它不连接 `platform`，也不执行用户 SQL。

- 推荐用词：分析所有者身份
- 避免用词：超级用户、迁移账号（单独使用时无法区分库）
- 相关概念：分析只读身份、平台身份

## 界面

### 查询工作台

首轮唯一的前端界面：输入一条 SQL、提交、展示执行中状态，并显示结果表或拒绝/失败原因。它不是运营后台，也不提供历史检索或图表编辑。

- 推荐用词：查询工作台
- 避免用词：控制台、报表页、分析平台首页
- 相关概念：查询运行
