# 设计文档

本目录保存 DecisionHarbor 的长期设计：范围、目标/非目标、术语与场景、不变量、模块边界、关键决策、失败/迁移、测试接缝与延后决策。

## 当前状态

首轮设计已建立：显式 SQL 受控执行链路的范围、模块与数据流、查询状态与审计、双库与只读身份边界、SQLGlot AST 策略与资源限制、最小 API 与错误语义、查询工作台、迁移与幂等 seed、Compose 并行隔离与测试接缝。

## 既有内容

- [`first-round.md`](first-round.md) — 首轮权威设计（显式 SQL 受控执行链路）。
- [`CONTEXT.md`](CONTEXT.md) — 已确认的领域术语与概念边界（源自背景与数据契约）。

## 设计文档模板（最小）

新建设计文档时至少覆盖：

- 范围与目标/非目标
- 术语与场景（引用 `CONTEXT.md`）
- 不变量与模块边界
- 关键决策与取舍
- 失败模式与迁移策略
- 测试接缝
- 延后决策

没有真实内容时不批量生成专题文档。
