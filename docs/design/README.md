# design/ 目录

保存长期边界、领域模型、接口、数据与关键决策。

与 `background/`（来源）、`plan/`（安排）、`status/`（当前状态）分离：本目录只记录已确认且长期有效的设计事实。

## 何时写入

- 定义模块边界、接口契约、数据模型或不变量时；
- 记录已确认的取舍与决策时。

## 模板

每个专题文档至少包含：

- 范围与目标/非目标；
- 术语与场景；
- 不变量与模块边界；
- 关键决策及理由；
- 失败/迁移影响；
- 测试接缝；
- 延后决策。

领域术语首次在设计中出现时，另建 `CONTEXT.md` 维护术语与概念边界，避免散落各文档。

## 现状

本目录当前仅含本说明，暂无专题设计文档。
