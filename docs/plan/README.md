# 计划文档

本目录保存 DecisionHarbor 的阶段计划：阶段大计划、垂直任务、依赖、未规划区、机械/行为/共识验证与交付边界。

## 当前状态

首轮实现计划已建立：[`first-round.md`](first-round.md) — 按依赖顺序的 9 个切片与验证边界。

## 计划归档

本项目当前不采用计划归档；如未来采用，历史计划放入 `history_plan.md`。

## 计划文档模板（最小）

新建计划文档时至少覆盖：

- 阶段目标与非目标
- 垂直任务切片与依赖
- 未规划区
- 验证：机械（构建/迁移/seed）、行为（策略/集成/主流程）、共识（审查确认）

没有真实内容时不批量生成专题文档。
