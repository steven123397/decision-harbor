# 计划文档

本目录存放阶段目标、任务切片、依赖关系和验证标准。

## 何时写入

- 新阶段开始前制定计划。
- 计划变更时更新对应文档，过期计划归档或删除。

## 文档模板

每篇计划文档建议包含以下结构（按需裁剪）：

```markdown
# <阶段/任务名称>

## 阶段目标

本阶段要达成的可验证结果。

## 任务切片

| # | 任务 | 依赖 | 验证方式 | 状态 |
| --- | --- | --- | --- | --- |

## 未规划区

已知但本阶段不处理的事项。

## 验证标准

- 机械验证：类型检查、lint、测试命令。
- 行为验证：手动或自动化确认的功能表现。
- 共识验证：需要人工判断的设计或产品确认。
```

## 规则

- 计划只维护当前有效版本；已完成阶段可归档为 `history_<name>.md`。
- 新增文档后同步更新 `docs/index.md`。
