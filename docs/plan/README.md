# plan 目录

阶段目标、任务切片、依赖、验证与交付边界。计划面向执行，完成后标注状态；长期结论沉淀到 `design/`，当前事实同步到 `status/`。

## 何时新建计划

当一个阶段或一组可交付任务需要拆分时建立；颗粒度以能独立执行和验证为准。

## 模板

每篇计划按以下结构组织，无内容的小节可省略：

1. 阶段目标：本阶段要达成的可验证结果。
2. 交付边界：包含与不包含的范围。
3. 任务切片：可独立执行的最小任务，标注负责人或工作区（如适用）。
4. 依赖：任务之间与外部的前置条件。
5. 验证：
   - 机械验证：格式、静态检查、构建等自动检查。
   - 行为验证：测试命令与预期结果。
   - 共识验证：需要人工确认的验收点。
6. 未规划区：明确不在本阶段处理的事项。
