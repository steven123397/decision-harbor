# Plan 文档说明

`docs/plan/` 将已确认的背景和设计拆成可执行交付。计划可以覆盖一个阶段，也可以覆盖一个端到端垂直任务；必须写清依赖、范围外事项、验证方式和完成边界。

计划不承担长期决策。执行中发现设计缺口时，先更新或补充 design 文档，再调整计划。

## 最小模板

```markdown
# <计划名称>

## 阶段目标与交付边界

## 依据

## 依赖与前置条件

## 垂直任务

### <任务名称>

- 结果：
- 影响边界：
- 验收条件：

## 未规划区

## 验证

### 机械验证

### 行为验证

### 共识验证

## 完成与归档
```
