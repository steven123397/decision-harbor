# 状态文档（status）

## 职责

维护项目当前事实：结论、进展、风险与下一步。只保留仍然有效的信息。

这里写「现在怎样、接下来优先做什么」，不写完整设计或完整计划正文。

## 文件

| 文件 | 用途 |
| --- | --- |
| `project_status.md` | 项目级当前状态（默认维护） |
| `code_review_status.md` | 长期审查发现台账（需要时再创建） |

```markdown
- 

## 下一步

- 

## 最近验证

- 命令：
- 结果：
```

## 更新节奏

- 阶段切换、合并重要能力、出现阻塞或交接给新 Agent 时更新。
- 不要把已过时细节堆成日记；过期内容删除或链接到 plan 归档。
